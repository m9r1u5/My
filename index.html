Command sweep

Tap Target on a writable characteristic, then send a template many times with one byte stepping through values. Put XX where the changing byte goes. Useful for finding unknown commands on lamps, LEDs and toys. Watch the gadget and the log.

Find a light by switching it off

  1. Light on, wait a minute → Scan network → Save as snapshot (“Light on”).
  2. Switch the lamp off at the wall/lamp switch (not in an app), wait 1–2 minutes → Scan network.
  3. Pick “Light on” → Compare. Whatever is gone is the light.

Run each scan twice if you can. Some devices sleep and miss a scan.

Listen for smart devices

Smart bulbs and plugs (especially Tuya / Smart Life) announce themselves every few seconds. This listens for 15 s and decodes what it can. It also asks TVs, speakers and routers to identify themselves.

Nearby Wi-Fi hotspots

A smart bulb in pairing mode makes its own hotspot (e.g. “SmartLife-1A2B”, “ESP_…”). To force pairing mode: switch the lamp off/on 3–5 times about 1 s apart until the bulb blinks fast, then tap below.

Open a device

Some gadgets have a built-in web page. Enter an IP (or tap “Web” on a device above).

Inspect an app or firmware file

Pick the old gadget app (.apk, .xapk, .apks) or a firmware .bin. Everything is processed on your phone; nothing is uploaded. It pulls out Bluetooth UUIDs, web addresses, possible hex commands and clues about which chip/platform the gadget uses.

Bringing a dead gadget back

  1. Scan on the Bluetooth tab with the gadget powered on. If it doesn't show, it may only talk over Wi-Fi, or it may need a button press to pair.
  2. Connect and look at the services. Tap Read on everything readable — names, firmware versions and model numbers help you search online.
  3. Tap Notify on notify-able characteristics, then press the gadget's own buttons. Anything that appears in the log tells you how it reports things.
  4. Get the old app's APK (APKMirror/APKPure, or pull it off an old phone with “APK Extractor”). Open it in App / File. Copy the UUIDs into “Extra service UUIDs”, scan again, and try the hex commands it found.
  5. Still stuck? Use the Command sweep on a writable characteristic and watch for the gadget reacting. Save anything that works as a button.
  6. Use Copy report and the Log to paste findings into Claude for help decoding them.

Phone support

Android: open in Chrome and tap Install. Bluetooth needs Location and Nearby devices permissions turned on for Chrome.
iPhone: Safari can't use Bluetooth or USB from web apps. Open this page in the free Bluefy browser for Bluetooth. The App / File and Tools tabs work everywhere.
Sweeping and writing random commands is usually harmless on lamps and toys, but don't sweep anything that controls mains power, heating, locks or batteries' charge settings.
